# Vibe Coding 教学资料

面向高校校企合作教学的 Vibe Coding / AI 编程启蒙资料，开放授权（CC BY 4.0），可直接复用。

## 内容结构

| 路径 | 说明 |
|---|---|
| `knowledge-base.md` / `knowledge-base.html` / `knowledge-base-slides.md` | 18 章 AI 编程知识库（含 3 个附录：Prompt 速查 / Git 速查 / FAQ） |
| `script-session1.md` | 第一课逐分钟讲师脚本（90 分钟） |
| `script-session2.md` | 第二课逐分钟讲师脚本（15 个 Part） |
| `script-session-harness.md` / `script-session-harness-v2.md` | 番外篇：harness 讲师脚本 v1 / v2 |
| `session1.html` / `session2.html` / `session-harness.html` / `session-harness-v2.html` | 上述脚本的自包含 HTML 版（浏览器直接打开） |
| `Session1.pdf` / `Session2.pdf` | 课程讲义 PDF |
| `Example/` | 课堂演示示例：个人介绍页、智能记事本（讲师制作，非学生作品） |
| `farewell-letter.html` | 收尾环节「让 AI 给自己写一封信」示例 |

## 使用方式

- 从 `knowledge-base.md` 了解整体知识体系与阶梯设计
- 直接看 `script-session*.md` 上手课堂逐分钟脚本
- HTML / PDF 可直接打开，无需任何环境
